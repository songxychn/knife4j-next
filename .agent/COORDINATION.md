# 独立审查与协作

主 agent 端到端负责复现、实现、验证和 PR。代码与行为变更在合入前应经过独立上下文审查（独立 reviewer agent 或维护者人工 review）；纯文案/错别字/链接修正由维护者合并前审阅即可。

## 审查要点

- Reviewer 使用独立上下文，自行核对真实 `git diff` 与验证证据，审查阶段只读不改代码。
- 聚焦正确性、回归、兼容性、安全边界与测试覆盖；范围外想法记为后续 issue，不隐式扩张当前 PR。
- 任意新 push 后须确保当前 head 的验证与 CI 全绿；修 review 使用普通追加提交。
- 独立 reviewer 提示词见 `.agent/prompts/reviewer.md`。

## 可选 worker

仅在并行探索或文件所有权明确隔离有实际收益时使用 worker；清晰指定负责文件范围、验证命令与完成条件即可。
