`5.7.8` 在 `5.7.7` 基线上纳入已合并的 springdoc / Boot BOM 修复（PR #872）。Boot3 生成器支持下限随依赖调整，升级前须检查应用的 Boot / Framework 组合。

MVC、WebFlux 与独立聚合的 smoke 使用真实 Boot `3.4.7` BOM；Boot35 MVC 使用真实 Boot
`3.5.1` BOM，均检查实际 Framework `6.2.8`。Gateway 使用自己的既有 Cloud/Boot 组合，

值。这是 [Swagger 上游修正](https://github.com/swagger-api/swagger-core/pull/5112)。迁移配置见

[#844](https://github.com/songxychn/knife4j-next/issues/844)。

## 5.7.9 前端与浏览器要求

Java 依赖沿用 5.7.8。OAS3 React / Knife4x Go v0.8.8 要求 Chrome/Edge 112、Firefox 116、Safari/iOS Safari 17；OAS2 Vue3 要求 Chrome/Edge 117、Firefox 119、Safari/iOS Safari 17.4。
这是相对上一版提高的浏览器下限，不应将本次补丁视为旧浏览器无感兼容。完整原因、旧版对照及验证边界见[兼容矩阵](./compatibility#浏览器基线)。

## 5.7.10 依赖与示例生成修复

Boot4 WebMVC、Gateway、独立聚合和 Demo 更新至 Boot `4.1.2`；Cloud `2025.1.3`、springdoc `3.0.3` 与 Java 17 下限保持。Jackson 2 对齐 `2.22.4`、Jackson 3 对齐 `3.1.8`，消费方仍须按 [Jackson 告警处理](../guide/faq#jackson-依赖告警处理) 核对自己的 BOM 和依赖树。Boot2/3 发布依赖未随 Demo 专用加固改变。

共享 React UI 修复 Schema 示例重复搜索、过早耗尽预算的问题；Go `v0.8.9` 同步此修复。浏览器要求沿用 `5.7.9` / Go `v0.8.8`，运行时最低版本与 OpenAPI 消费范围不变。

## 5.8.0 功能与修复

新增完整单接口 Markdown 复制和 OAS3 WebMVC 启动摘要，修复 Schema 示例生成与 Boot3.5 MVC Gateway 服务发现刷新；Go `v0.9.0` 同步共享 UI。源码构建统一要求稳定 Node `26.x`；Java/Go、浏览器及依赖矩阵沿用上一版。详见[发布说明](../release-notes/)。

## 如何确认你项目中的实际版本

```bash
mvn dependency:tree -Dincludes=com.baizhukui
mvn dependency:tree -Dincludes=org.springdoc
mvn dependency:tree -Dincludes=org.apache.commons:commons-lang3
```

如果 springdoc 版本与上表不一致，说明你的项目中有其他依赖覆盖了版本管理。请检查是否有 BOM 或父 POM 引入了不同版本的 springdoc。

如果安全扫描提示 `CVE-2025-48924`，重点确认 `commons-lang3` 是否低于 `3.18.0`。使用 Spring Boot parent 或
Spring Boot BOM 的应用可能会把 starter 传递声明的 `commons-lang3` 版本重新管理回 Boot 自带版本；这种情况下需要在应用侧
`dependencyManagement` 中显式覆盖到 `3.20.0` 或更高版本。
